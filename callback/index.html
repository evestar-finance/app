Finish the connection

  1. Click the address bar of this browser window, select the complete address and copy it. It contains the values code, state and realmId that the tool needs.

The authorization code in the address can be used once and expires within minutes. Share the address only with the operator of Evestar Accounting Bridge who asked you to connect, and close this tab afterwards. If the code expires before it is used, the connection is simply started again from the tool.
