The application has been disconnected

Evestar Accounting Bridge

You have disconnected Evestar Accounting Bridge from a QuickBooks Online company. From this moment the application can no longer access that company: its next attempt to renew its access will fail, and a new authorization is required to connect again.

To complete the removal on the computer

  • The operator uses the revoke function of the tool for that company. It deletes the local token file (secure\tokens.production.json, inside the local profile folder of that company).
  • Once the application is disconnected, a token file left on the computer no longer grants access, but deleting it is the clean way to finish.

What disconnecting does not do

  • It does not delete the accounting data inside QuickBooks Online. That data belongs to the QuickBooks company and remains there.
  • It does not delete the local log files (logs\qbo_audit.jsonl and logs\qbo_requests.jsonl) kept on the computer where the tool ran. They remain until they are removed as described in the Privacy Policy.

To connect again

A new connection is started from the tool on the authorized computer, as explained on the connection page.

Deletion requests

To request deletion of locally stored records, write to eduard@evestar.com with the subject line "Privacy request - Evestar Accounting Bridge".
