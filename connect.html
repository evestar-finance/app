Connecting to QuickBooks

Evestar Accounting Bridge

Evestar Accounting Bridge is a desktop tool operated by authorized personnel of Evestar Group LLC. A connection to QuickBooks Online is never started from this website: it is started from the tool itself, on the authorized computer where the tool runs.

How a connection is established

  1. On the authorized computer, the operator starts a new connection from the tool. The tool prepares the OAuth 2.0 authorization request, including its anti-forgery state value, and keeps a record of it on that computer for a limited time only.
  2. Intuit's authorization page opens in a web browser. A user of the QuickBooks Online company with sufficient rights signs in to Intuit, chooses the company and approves the connection.
  3. Intuit then sends the browser to a static page of this website. That page asks for its complete address to be copied and given back to the operator of the tool; the page itself does nothing with it.
  4. The tool checks the returned state value against the record it kept and exchanges the authorization code directly with Intuit, from the authorized computer.

Because the state value is created and checked on the authorized computer, a connection can only be completed there. There is no way to connect the application from this page.

Reconnecting

If a connection expires or has been disconnected, it is re-established in the same way, from the tool on the authorized computer. Intuit may direct you to this page when that is necessary; no action is required on this website.
